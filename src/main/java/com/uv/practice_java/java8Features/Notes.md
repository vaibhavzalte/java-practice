* Java 8 :- Lambdas, Streams, Optional, Date-Time API

## Q. What are the major features introduced in Java 8?
### Ans: 
The major Java 8 features are:
1. Lambda expressions
2. Functional interfaces
3. Stream API
4. Method references
5. Optional class
6. Default and static methods in interfaces
7. New Date and Time API

## Q. What is Lambda Expression in Java?
### Ans:
- A lambda expression is a short way to write an anonymous function (no name) that implements a Functional Interface.
OR
- Lambda expressions help reduce boilerplate code and enable functional-style programming.
